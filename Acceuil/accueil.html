404 – La Page Perdue

Tu es un développeur web qui travaille sur un site mystérieux. Un jour, une page “404” apparaît… mais elle ne devrait pas exister.

En cliquant dessus, tu es aspiré dans le code du site lui-même. Chaque page est un fragment corrompu du web, rempli de bugs, de virus, de lignes de code vivantes et d’énigmes numériques.

Ta mission : réparer le système et retrouver la page d’accueil avant que le site ne s’efface… avec toi dedans.

Structure du jeu

  • Accueil – Présentation du jeu, ambiance glitchée
  • 404 – La page perdue – Point de départ de l’aventure
  • Les LesBackstages – Salle où les fichiers sont effacés
  • Le Navigateur Bug– Interface déformée
  • Le Terminal – Salle en ligne de commande
  • La Corbeille– Fichiers supprimés mais pas oubliés
  • Fin du jeu – Victoire
  • Mon Cv - anglais et francais
